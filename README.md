# FindMyCountry

This project called 'Find my country' is only demostration of how we use DevOps tools in real live.

## Used Tool:-
1. dotnet, ms build, .Net 10
2. Jenkins
3. docker
4. docker compose

## Workflow:-
1. Create a project
2. Test the project on IIS server on developer device
3. Install a jenkins server and create pipeline in it.
4. Run Docker compose commands as follow
```
docker compose up
```
